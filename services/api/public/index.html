安装扩展

开发预览版 · Chrome Manifest V3 · 数据仅在本地处理

⤓ 拖拽安装 （拖到 chrome://extensions 开发者模式页面） 下载 zip
  1. 构建扩展：pnpm --filter @stylelens/extension build
  2. 打开 chrome://extensions → 开启「开发者模式」
  3. 把上面的按钮拖到该页面（或点击「下载 zip」解压后点「加载已解压的扩展程序」选择 stylelens/ 目录）
  4. 按 Alt+Shift+S 开始选择元素

注：Chrome 对拖拽安装有策略限制；若拖拽未生效，请使用「加载已解压的扩展程序」路径。 本扩展访问的后端服务仅在本地 localhost 运行。
