开发者模式

Why not CRX? Standard Chrome requires a Chrome Web Store proof for many local CRX installs. This project cannot create Google's private signature, so ZIP loading is the dependable option.

安装路径

一个扩展，三步完成安装。

下载 ZIP，解压后在 Chrome 的扩展程序管理页加载文件夹。

01

打开 Chrome 扩展程序管理页

在地址栏输入 chrome://extensions。

02

开启开发者模式

打开页面右上角的“开发者模式”，显示本地扩展操作。

03

加载解压后的文件夹

点击“加载已解压的扩展程序”，选择从 stylelens.zip 解压出的文件夹。

关于安装

Chrome 的扩展安装页不接受书签链接。请使用 ZIP 和“加载已解压的扩展程序”完成本地安装。
