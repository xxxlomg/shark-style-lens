开始使用

三分钟，把它装进 Chrome。

下载 ZIP，解压，在扩展程序页面加载文件夹。安装完成后，StyleLens 会出现在你的浏览器工具栏里。

stylelens.zip Chrome Developer mode package ZIP
下载后解压，再选择解压出的文件夹。
下载 ZIP

Why not CRX? Chrome 对本地 CRX 文件存在签名限制。ZIP 加载是本地开发最稳定的方式。

使用方式

从一个元素，得到一份能用的 Prompt。

它不会只看一张图。StyleLens 同时读取浏览器里的结构证据和精确目标截图。

01

选中你想复刻的 UI

按 Alt+Shift+S 开始选择，也可以点击扩展图标。

02

让浏览器拆解它

读取 DOM 子树、CSS、布局、状态和组件关系，并截取一张精确目标图。

03

复制 Prompt，开始构建

Vision 证据和 DOM Profile 合并后，Prompt 会在页面浮层中流式生成。

为什么更接近目标

一张图，三层证据。

截图负责看见外观，DOM 负责说明关系，Agent 负责把它们写成可执行的构建意图。

视觉边界

只看你选中的那一块。

单张截图严格按照目标元素的 DOM 矩形裁剪，周边进度条和扩展 UI 不会抢走注意力。

captureVisibleTab → target PNG
